# Проверка поведения

Перед проверкой прочитайте `skills/russian-editor/SKILL.md`. Для каждого случая из `cases.json` в отдельном контексте передайте скилл, запрос и исходный материал. Не передавайте ожидаемый результат: это условия для проверяющего, а не подсказка редактору.

Сохраните фактический ответ, название модели, дату и способ проверки. Сопоставьте ответ с полем `criteria`. Допускайте разные формулировки, если условия выполнены.

Проверяйте прежде всего изменение смысла: факты, исполнителя, ограничения, отрицания, состояние работы, происхождение утверждения и действие адресата. Отдельно проверяйте соблюдение запрошенного режима. Для точечной правки изменения вне границ запроса считаются ошибкой.

Набор не измеряет вероятность ИИ-авторства. Суммарное число пройденных случаев относится только к этим случаям, модели и способу проверки.

`results.md` содержит контрольные ответы автора пакета. Это самопроверка в одном сеансе, без независимого агента; она слабее отдельного воспроизводимого запуска на выбранной модели. При независимом прогоне храните его результаты отдельным файлом и не заменяйте самопроверку утверждением о независимой оценке.
