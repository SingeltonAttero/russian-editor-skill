Для проверки обнаружения Codex использован параметр конфигурации только на время команды, без записи в пользовательские настройки. Повторите из корня пакета, заменив путь абсолютным путём своего checkout:

```sh
codex \
  -c 'marketplaces.russian-editor-marketplace.source_type="local"' \
  -c 'marketplaces.russian-editor-marketplace.source="/absolute/path/to/russian-editor-skill"' \
  plugin list --marketplace russian-editor-marketplace --available --json
```

Ожидается доступная запись `russian-editor@russian-editor-marketplace` с версией `1.1.0`. В проверенном окружении она имела `installed: false`, `enabled: false`: обнаружение в каталоге не означает установку или активацию.

Схема переносимого манифеста: [Agent Plugins 1.0.0](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json). Формат временных настроек каталога: [конфигурация Codex](https://learn.chatgpt.com/docs/config-file/config-reference). Для YAML-валидатора использован временный запуск через `uv` с `pyyaml`, для проверки JSON Schema также `jsonschema`; эти зависимости не нужны пользователю скилла.

Проверка копирования не запускает клиент агента и не подтверждает, что он загрузил скилл или правильно выполнил текстовую задачу. OpenCode установленной версии v2.0.20 не запускался на редакторской задаче. Проверка ответов моделей в Codex, Claude Code и OpenCode остаётся отдельной работой; текущие контрольные редакторские ответы находятся в [results-1.1.md](results-1.1.md).
